# 从本地排版到发布

## 交付状态

默认给出可复制 HTML、可编辑稿和素材位置。可复制 HTML 中只复制正文容器，标题和摘要单独填；图片内嵌用于本地预览与复制，粘贴后仍需核对微信是否真正接收了图片，不能假设 data URL 已变成微信素材。

草稿上传使用 `article.json` 与图片占位符版本的 `content.html`；脚本将图片上传微信后替换占位符，不上传本地 file URL 或 data URL。构建器不会发布内容。

用户明确要求存草稿时，可用同仓库的 `ai-pioneer-1019/scripts/Save-WeChatDraft.ps1`；先读该技能 [微信草稿说明](../../ai-pioneer-1019/references/wechat.md)。该脚本只存/更新草稿，不公开群发。其本地凭据方案不适用时，使用已授权后台或当前环境可靠发布器，不索要用户把密钥写到聊天或提交到 Git。

```powershell
pwsh -NoProfile -File <repo>/ai-pioneer-1019/scripts/Save-WeChatDraft.ps1 -ArticleJsonPath <issue>/render-v1/article.json -OutputDirectory <issue>/upload-v1
```

现有草稿先读回，与用户最新后台内容对比，再更新同篇草稿；保留快照。来源未知的旧本地稿不能覆盖远端。超时可能已写入，先查状态，不盲目重复创建。

通用发布器的样式检查若只支持 1019 默认参数，不能据其默认值把访谈改回通用版式。保留本技能的 15px/2/0.3px 与黑色标题，并直接检查微信读回 HTML 的实际视觉。发布器的长度或图片限制也不是缩写访谈的授权；先核实当前平台限制，再压缩冗余标签或与用户协商拆篇。

## 核验与公开发布

保存后读取并核对标题、摘要、人物封面、完整问答、图片数量及顺序、推荐文章目标链接；查看首屏、至少一处长问答、结尾。只上传成功未读回时，报告“待核验”。本地截图不能证明后台保存成功。

仅准备草稿的授权不包含公开发布。若用户已明确要求公开发布当前最终稿，按当前账号可用流程执行，不再重复索取同一授权；需要用户扫码或平台确认时明确交接。公众号发布状态与公开 URL 要在平台实际结果中确认。工具只有存草稿能力时，做到草稿可审阅并说明剩余发布步骤，不假称已发布。

## 复盘

收到最终发布 URL 后重新读取成品，记录四类差异：标题承诺、Highlights 的信息顺序、实质内容改动、排版参数。与原版对照提炼有效习惯，不把本篇具体数字/措辞/人物/推荐链接写成默认值。公开仓库只保存可复用规则、短案例分析和模板，不提交用户完整改稿、下载原视频、账号配置、运行回执或浏览器 Cookie。
