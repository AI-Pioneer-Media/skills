# 改稿记录与可选发布

## 持续学习

用户说“同步这轮修改”时，读取相关稿的最新正文和批注，保存真实结果，建立前后差异。读取未给 `content.through_sequence` 时，使用完整快照比较，不拿 `metadata.current_sequence` 代替守卫。修改 Page 时用新读取的块 ID、哈希及实际图片引用；保留批注锚点和图片元数据，不用旧全文覆盖新稿。

本地项目的协作连接可配置在 `project-connection.json`；公开包默认未连接。已初始化的文档不重复初始化。新文档建立自己的连接、底稿和版本序号，不沿用其他文章的 Page ID。

将每轮结果分为：

- **明确反馈**：用户实际说了什么，作用于哪里。
- **观测到的改动**：前后文字、块 ID、图位、时间及可读作者信息。
- **编辑判断**：猜测为何这样改、怎样用于以后，标明待验证。

只有来源可核验时归因为 user。代理改稿写 agent，无明确归因写 unknown。追加记录，保留历史版本；相同快照不制造一次新改稿。未完整读取的批注和历史须保留不完整标记。

后续写稿先读取新偏好和相关例子。技能中沉淀通用决策与有范围的例子，而非把每次具体措辞写成禁令。没有后台自动化时，只承诺读取并同步的轮次已记录，不声称每次敲键盘实时学习。

## 私有备份

仅在用户已授权私有 GitHub 备份时执行。每次上传前确认仓库仍为 private，只提交本次协作文件，保留其他任务的改动；上传后核对远端提交。换到新仓库或新用户时不能继承其他项目的授权。技能安装目录与仓库副本若同步，核对内容一致；不替用户改公开分享权限。

## 用户明确要求公众号草稿时

完整文章与配图先准备好，再调用草稿接口。当次已授权发布到草稿箱，执行时无需重复询问；普通出稿不自动变成群发。账号与作者按用户当前要求核对，不沿用其他技能中的AI Pioneer身份。

优先采用可用的公众号发布能力；走微信官方 API 时查当前官方说明。先读当前可编辑稿与批注，再冻结本次上传快照，保存非敏感的排版、图片来源与核对记录。不要直接复用文章专用脚本中的固定标题、源链接、图数或“开头两张banner”校验。

凭据只从当次获准的安全输入、环境或密钥设施读取，保存在内存。不能写进技能、配置示例、文章、日志、GitHub 或 shell 历史；不能把用户曾给出的真实 AppID/AppSecret复制到可复用脚本。终端输入时关闭回显；错误输出须去除凭据与 access_token。

推荐实际发布步骤：

1. 对当前稿核对标题、作者、摘要、封面、正文与真实图片文件。
2. 用 `stable_token` 获取调用凭据；白名单错误读取实际返回的出口 IP，明确告诉用户需要添加哪个 IP，不自行猜测或反复索要同一授权。
3. 静态正文图片使用 `media/uploadimg`，GIF 可使用支持 GIF 的 `material/add_material?type=image`，以当前文档与实际响应为准。WebP 转换成受支持格式时检查像素，原图留存。
4. 上传封面永久图片，组装 `article_type:news` 的图文。用户已明确要求后续都不加“阅读原文”，因此 `content_source_url` 保持空字符串，除非用户后来明确改变此要求；正文内的必要来源引用与本地研究记录仍保留。正文不加重复标题、固定广告和未经用户选择的图。
5. 调用 `draft/add` 一次，立即保存返回的草稿 `media_id`。请求结果不明时，先用回执或 `draft/batchget` 找唯一匹配稿，不能盲目重复新增。已有草稿的更新需对应明确的更新范围。
6. `draft/get` 回读：核对标题、作者、摘要、封面、段落文字、图文顺序、图片身份、宽度与必要留白；对实际草稿 GIF URL 检查格式和帧数。不能把 `/0` 变为 `/640` 等 CDN 规格差异误判为换图。
7. 最终告知草稿创建和核对结果，给出可用入口；API成功与微信客户端视觉预览分开陈述。

没有真实成功响应和回读核对，就不能称“已发布到草稿箱”。接口因权限或外部状态阻塞时，保留完整可审阅稿，说明实际阻塞与用户需要完成的具体动作。

官方入口：[上传正文图片](https://developers.weixin.qq.com/doc/service/api/material/permanent/api_uploadimage)、[永久素材](https://developers.weixin.qq.com/doc/service/api/material/permanent/api_addmaterial)、[新增草稿](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_draft_add)、[读取草稿](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_getdraft)。这些地址在本案例发布时已读取；未来执行仍以当前文档和实际接口为准。
