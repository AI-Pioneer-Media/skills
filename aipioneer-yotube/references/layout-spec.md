# AI Pioneer 最终稿排版规范

## 版式层级

| 元素 | 样式 | 用途 |
|---|---|---|
| 正文 | 16px，`#333333`，行高2，左右8px，下16px | 一段一意 |
| 蓝色判断 | 16px，粗体，`#007AAA` | 关键判断、追问、分类标签、反差数字 |
| 荧光绿结论 | 16px，粗体，背景`#73FCD6` | 全文最重要、值得截屏的结论 |
| 黑色粗体 | 16px，粗体，`#111111` | 动作、定义、人物问题 |
| 灰底卡片 | 16px或18px，粗体，黑字，`rgba(0,0,0,.06)`，圆角8px | 阶段性收束、公式或路径 |
| 章节数字 | 80px，粗体，`rgba(0,0,0,.08)` | 01、02等视觉锚点 |
| 章节标题 | 24px，粗体，黑色，行高1.3 | 承载完整判断 |
| 图注 | 13px，`#888888`，居中，行高1.65 | 说明来源和画面意义 |

## Markdown 标记

强调内容先拆成独立段落，再使用：

```markdown
[BLUE]基础模型会补掉什么？到那时，你的公司还剩下什么？[/BLUE]

[GREEN]真正值得小团队下注的，是模型成功率不到1%的任务。[/GREEN]

[BOLD]模型为什么做不到？[/BOLD]

> 找到最贵的瓶颈，建立高速验证闭环，让每次实验为下一次积累能力。
```

不要在一个段落里叠加蓝色、绿色和灰底；不要连续三段使用同一种强调。

## 强调用量

- 蓝色：通常每个主要章节1—2处，负责导航读者的判断。
- 绿色：长文通常4—6处，只有删掉会损害全文主线的句子才可使用。
- 灰底：通常每章不超过1处，开场总论和结尾路径可以额外使用。
- 黑色粗体：用于问题、步骤和定义，不承担最高层结论。

如果每屏都高亮，等于没有高亮。

## 图片顺序

1. H1后放 `01-header-logo.png`；
2. 紧接YouTube缩略图和图注；首张内容图不加圆角；
3. 开场正文；
4. 正文中放2—4张能证明内容的截图或官方图片，圆角8px；
5. 参考资料之后依次放 `03-about-services.png`、`04-follow-banner.png`、`05-star-guide.png`；
6. 不放 `02-business-contact.png`。

## 排版边界

- 不用彩色大面积背景、渐变、阴影或装饰线堆砌视觉。
- 不把整段普通事实涂绿；绿色必须是作者愿意让读者截图保存的句子。
- 图注写清来源，不使用“网图侵删”。
- 参考资料保留可识别的来源名称；链接是否可点受公众号编辑器限制，不把可点击性当作上传成功条件。
