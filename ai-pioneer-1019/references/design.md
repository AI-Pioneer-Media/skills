# 1019 视觉定稿

固定源文件及导出 JPG 是准确参考，不是继续自由探索风格的起点。版式围绕人和观点，以文字层级、留白和少量朱红建立辨识度。

## 配色与字体

| 元素 | 规范 |
| --- | --- |
| 品牌朱红 | #D93D28 |
| 正文墨黑 | #151515 |
| 背景与反白文字 | #FFFFFF |
| 常规中文 | PingFang SC / Microsoft YaHei / sans-serif |
| 正文大标题、提炼句 | SimSun / Songti SC / serif |
| 人物封面 | 高对比衬线英文姓名 + 宋体风格朱红职务 |

最多三种设计色。照片不做强制三色量化。水印的淡灰来自墨黑低透明度，不新增强调色；白底长文中允许必要的自然照片。

## 顶部 banner

1050 × 218，朱红底，白字。左右内边距 56，上下 40。两列 400px / 剩余空间，间隔 64px，垂直居中。左列 `AI PIONEER` 单行，52px / 600 / 1.1，字距 -0.7px；右列 `记录 AI 先行者的` 换行 `思考与行动`，38px / 500 / 1.55，字距 0.5px。无图形 Logo、圆圈、竖线、阴影、渐变或磨砂。字标本身保留。

## 正文排版

容器最大宽 677px，图片宽 100%，使用行内样式。手机预览 390/430px，左右 20px。微信实机外边距由客户端承载，正文容器不额外套大幅缩窄的 padding。

| 组件 | 字号/行高 | 留白 |
| --- | --- | --- |
| 正文主标题 | 29px / 1.4，宋体粗体 | 上 26，下 24 |
| 正文 | 16px / 1.95，字距 0.3px | 段落间 16 |
| 导语 | 同正文 | 下 36 |
| 章节序号 | 11px / 1.4，朱红，700 | 下 8 |
| 章节标题 | 20px / 1.5，700 | 下 15，章节前 36 |
| 观点提炼 | 22px / 1.7，宋体粗体；朱红引号 48px | 上 34 |
| 结语 | 20px 标题，16px 正文 | 上 40 |
| 全文完 | 11px / 1.8，朱红，字距 4px，居中 | 上 40，下 48 |

章节数量由内容决定，不能把所有文章压成四段。观点提炼不要伪装成人物原话：引用需要原文证据；编辑观点应明确为编辑提炼，不虚构署名。内容事实证据可保留在工作文档；用户不需要的参考尾栏不附加。

2026-10-20 修订：首图内部左侧朱红出血到画布左边，与 banner 可见左边缘对齐，不得留白色竖条。首图后的“AI 先行者 · 人物姓名”标签和“姓名 + 职务”信息行取消，避免复述图上已有信息。文章主标题仍保留，正常正文提到人物不受限制。

## 往期推荐

居中 `CONTINUE READING`（11px，朱红，字距 2px）与 `往期推荐`（20px，墨黑粗体）。默认 2 篇，用户给 3 篇时可用 3 篇。

每张输出宽 1050px；原封面区域 1050 × 448，object-fit:cover，检查裁切不伤人脸或原封面标题。圆角 16px。下方朱红底、白字标题栏内边距 22px 30px 28px：日期 26px / 1.5、字距 3px，标题 40px / 1.5 / 700，点击阅读 ↗ 26px。标题按完整内容自动增高，不截断。发布日期未知时不写日期。卡片之间 18px。

微信编辑器可能重写富文本链接并改变颜色，所以先把**原封面 + 日期 + 标题 + 阅读提示**渲染成单张 JPG，再用单个 `<a href="真实文章链接"><img ...></a>` 包住。卡片图片本身不具有跳转能力，不能忘记外层 a 标签。

## 品牌结尾卡片

固定复用 `assets/ending-card.jpg`。1050 × 1160，白底，上部墨黑字与朱红点缀，右上淡灰四角星 Logo 水印；下部 415px 朱红实色双栏。无玻璃、磨砂、横杠、装饰圆环。

文案固定为：

- AI PIONEER. / PEOPLE · IDEAS · ACTION
- 与AI先行者 / 同行（同行为朱红）
- 记录先行者的思考与行动，看见技术背后的选择、创造与改变。
- 人物与思想：对话创造者，追问关键选择。理解他们如何思考与行动。
- 工具与实践：走进真实工作，记录具体尝试。把新的可能带入日常。
- 关注 AI Pioneer，与AI先行者同行。

不要用旧版品牌介绍、关注、星标三张长尾替换这张卡片。文章结语与品牌卡片是不同组成部分，二者都保留。
